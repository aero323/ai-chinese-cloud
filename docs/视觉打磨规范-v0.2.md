## 四、熊猫出题（v0.2 新增）

### 1. 核心规则：**一页里只能有一个说话的人**

- 多邻国之所以"像游戏"，靠的是有个角色**一直在场**。我们的角色是熊猫 🐼（原本只在课堂页大恭喜露一次面）。
- 但角色只能有一个：**页面上已经有别的角色、对话气泡或场景图的，熊猫不要出现**——硬加进去就变成"三个人在说话"，更乱。
- 熊猫**只做一件事：站在那儿出题**。不做动作、不说话、不催、不加动效。
- **红线**：熊猫手里**不许拿任何跟答案有关的东西**（茶杯、食物、书本……），那等于把答案画在题面上。

### 2. 出场清单

| 情况 | 页面 |
| --- | --- |
| **出场**（纯文字、没有别的角色或图） | 快速选择、句子排序、补全句子、拼字/组词、找错误/改错 |
| **出场（按同一规则延伸，做之前再确认一次）** | 分类归组、拼音—汉字—含义匹配、课堂投票 |
| **不出场**（已经有人或有图） | 对话补全、情景选择、看图单选、图片—词语连线、连线配对、记忆翻牌、看图说话 |
| **待定** | 听音选图/选词、跟读模仿、开放问答（三个语音占位页；等音频/麦克风形态定了再定，占位期间可以不出场） |

### 3. 版面（照抄样板页）

- 结构：`.choice-stem` 变成一行——左 `.choice-avatar` + 右 `.choice-question-plate`（里面是拼音行 + 题干）。
- 形状：头像**圆形**；题目牌是**普通圆角矩形**，**不许做聊天气泡、不许有尖角或小尾巴**（对话补全那页才是气泡，两者必须长得不一样）。
- **插槽化**：头像表情只写在一处——`--avatar-glyph`（现在是 `"🐼"`）。将来换成自绘熊猫插画时，只替换这一个变量（换成 `background-image`），版面不动。
- 头像占位会让文字区变窄：**上线前用最长的题干试一遍**，窄屏（≤360px）允许把头缩到 40px。

## 五、弹窗规格（v0.2 更新，接口已换）

> 旧写法 `open({ badge, titleZh, titleId, actions })` 已废弃。现在按**档位**自动配色配表情。

```js
AICloudFeedbackModal.open({
  tier: "correct" | "correctFirstTry" | "wrong",
  badge: praise.emoji,      // 句池给的 emoji；不传时按档位兜底（🎉 / 🏆 / 💪）
  titleZh: praise.zh,
  titleId: praise.id,
  actions: [主, 次]          // 第一个自动是 primary-button，其余 secondary-button；次要按钮可用 icon: "↻"
});
```

| 部件 | 规格 |
| --- | --- |
| 弹窗内边距 | 34 / 22 / 26 |
| 徽章 | **98×98 圆**，emoji **56px**，出场 300ms 轻弹（`cubic-bezier(.2,.9,.3,1.45)`） |
| 标题 | **36px / 900 / `#221A3D`**，下方印尼语小字 |
| 按钮 | 最小高 **54px**，与页面按钮同款 |

### 三档配色

| 档位 | 徽章底 | 光晕 | ✦ 星星 |
| --- | --- | --- | --- |
| `correct`（答对） | 暖金 `#FFEFC9` | 14px `rgba(255,196,86,.16)` | 2 颗，金色 `#FFC761` |
| `correctFirstTry`（一次全对） | 暖金 `#FFEFC9` | **22px、更亮更散** `rgba(255,196,86,.18)` | **3 颗**（比普通答对多一颗） |
| `wrong`（答错） | 冷灰蓝 `#E9EEF8` | 14px `rgba(139,160,196,.14)` | 2 颗，冷灰蓝 `#9FB3D6` |

- ✦ 两颗固定在徽章的左上（17px）和右下（12px）；第三颗（14px，右上）只在"一次全对"档出现。
- 星星依次淡入（0.5s，延迟 0.18s）；**弹窗里只放情绪，不放事实**。

## 六、大恭喜（v0.2 新增）

- 它是**课堂页自己**的弹层（`classroom.html` 的 `.celebrate-overlay / .celebrate-card`），**不在任何题型页里**，也不许搬到题型页。
- 组成：熊猫 🐼（112px 圆、柔和渐变底、字号 70px）+ 6 条撒花 + 标题「今天的课堂互动完成啦！」+ 印尼语行 + 词卡列表（今天练过的词）+ **唯一出口**【太棒啦】。
- 它的作用是**标上限**：**单题页不许比它更热闹**——题型页不加撒花、不加第二条出口。
- 它和题型页共用 `styles.css` 里的 `.primary-button`：**改公共按钮时别把大恭喜改坏**。

## 七、自检三问（交页面之前问自己）

1. **第一眼看哪儿？** 打开页面，视线应先落在"题目 + 选项"，不是角标、也不是演示按钮。
2. **有没有多余的字？** 页面只留事实（题面、选项、对错、正确答案）；长解析、重复说明、客套提示都删。
3. **出口是不是唯一？** 每屏只有一个主动作（提交 / 返回课堂），其余动作降级为次要样式；不要出现两个"抢戏"的按钮。

## 八、红线

- 不放长中文解析、不放纯中文小字、不用"分数 / 排名 / 失败"这类词。
- 紫色 = 信号（选中、可提交），不拿它做装饰。
- 动效只做上面三样，150–300ms，一次只动一下。
- 一页里只能有一个说话的人；熊猫手里不拿跟答案有关的东西。

## 九、弹窗接线：做法与进度（2026-09-18）

> 模具样式全部限定在 `[data-feedback-modal]` 下：**没接线的页面完全不受影响**，可以一页一页接，不用等全体。

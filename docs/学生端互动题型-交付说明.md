# 学生端互动题型 · 交付说明（2026-09）

**一句话**：学生端四批共 16 个可复用互动题型已完成（第四批 4 个为「占位版」），加上原有 2 个（连线配对、记忆翻牌）共 18 个，全部接入统一入口「题型体验」。只动学生端，未动 `admin/**`。

## 一、题型清单（key｜玩法）
- 快速选择（choice）｜读题点选，提交后立即判分
- 句子排序（order）｜多邻国式：点词块排进上方「答案行」，可退回重排
- 补全句子（fill）｜从词库点选词语填空
- 课堂投票（poll）｜不计分，老师看统计
- 看图单选（picture）｜看一张图，从选项里选出正确的词（图片先用 emoji 占位）
- 图片—词语连线（picture-match）｜点左右两边的图和词，配对成功即锁定（点选式，不画线）
- 情景选择（situation）｜看场景，选出这个场合里最得体的说法
- 对话补全（dialogue）｜看上一句，选合适的下一句填进对话气泡
- 拼音—汉字—含义匹配（pinyin-match）｜看拼音选汉字，再选它的意思，一组一组配起来（闯关式）
- 分类归组（category）｜把词语一个个放进正确的类别，提交后看结果
- 拼字/组词（word-build）｜点字块，把词语拼进空格
- 找错误/改错（correction）｜读句子，点出用错的那个词，看正确说法
- 听音选图/选词（listening）｜占位版：播放是假流程，判分是真的
- 跟读模仿（read-aloud）｜占位版：假波形、假评分，不碰麦克风
- 看图说话（picture-talk）｜占位版：看一张图说一句话，看占位评分
- 开放问答（open-qa）｜占位版：回答一个开放问题
- 连线配对（match）｜原有题型，保留
- 记忆翻牌（memory）｜原有题型，保留

## 二、怎么体验（本地预览）
1. 打开 `/classroom.html`，点右下角紫色「题型体验」按钮 → 任选题型
2. 单独打开：`/interaction-<type>.html?type=<type>`
3. 课堂模式（模拟老师发题到学生手机）：`/interaction-<type>.html?type=<type>&mode=class&slot=1`，完成后自动回课堂并解锁下一题
4. 各题型完成弹窗里的「换一个题型」会回到课堂页并自动展开清单

# 题型任务书（第四批 · 占位版）

- **本批 4 个**：听音选图/选词、跟读模仿、看图说话、开放问答
- **定位：占位版**。只把页面样子和完整流程搭出来——**不放真声音、不做真录音、不做真识别**，这三样以后单独处理
- 为什么这么做：真识别要么接外部服务、要么做本地规则，方案没定；真录音在电脑浏览器上试也不代表手机上能用。先别卡在这里
- 第三批那 4 个常规题型（拼音匹配、分类归组、拼字/组词、找错误/改错）不受影响，按原任务书做正式版
- 只写任务书，不动代码

---

## 一、和前三批一样的部分

照搬，不另立规矩：

- 文件名固定 `interaction-<type>.html`，样式 `interaction-<type>.css`，脚本 `interaction-<type>.js`
- 体验模式：`interaction-listening.html?type=listening`；课堂模式：`?type=listening&mode=class&slot=1`
- 六个部件：顶栏、题型角标、进度「第 1 / 1 题」、作答区、双语底部提示条、完成弹窗
- 完成时调用 `AICloudActivity.finish({ correct, seconds })`
- 完成弹窗两个按钮：「换一个题型」→ `classroom.html?activities=1`，「返回课堂」→ `classroom.html`
- 不要修改公共文件，`shared/activity-types.js` 里只改自己那条

**怎么读这张表**

## 三、占位标识怎么做

占位版最怕的是演示时被当成真功能，所以标识要做三处，缺一不可：

### 1. 数据里加标记

`shared/activity-types.js` 里这 4 条记录加一个字段：

```js
{
  type: "listening",
  page: "interaction-listening.html",
  title: "听音选图/选词",
  ready: true,
  placeholder: true,   // ← 新增：占位版
  legacy: false
}
```

### 2. 题型清单里的标签跟着变

右下角「题型体验」清单里，这 4 行显示「可体验 · 占位」，和正式的「可体验」区分开。

### 3. 页面角落固定一个小标签

每页右下角放一个固定的「🧩 占位演示」小标签（不随滚动跑），位置和右下角的悬浮按钮错开，别挡住。

### 4. 暂时不进课堂随机抽题

占位版虽然 `ready: true`，但要**排除在课堂随机抽题之外**，避免课堂里抽到一个没有声音的题型。手动从「题型体验」进去体验没问题。

> 以后转正 = 把这一条的 `placeholder` 去掉，其余不用动。

## 五、听音选图/选词 · interaction-listening.html

### 5.1 页面上有什么

- 题面：一行提示「听一听，选出你听到的」
- 题型角标：听音选图/选词
- 进度：第 1 / 1 题
- 作答区：最上面一个大播放按钮「🔊 听一听」，下面 3–4 个文字选项，纵排
- 提交按钮：没选时不可点
- 反馈区：提交后出现
- 底部提示条：可以反复播放，听清楚再选。 / Boleh diputar berulang kali, dengarkan dulu.
- 完成弹窗
- 右下角「🧩 占位演示」标签

### 5.2 操作逻辑与状态

1. 进入：待作答，**不自动播放**
2. 点播放按钮：**不发出声音**，按钮下方出现一行小字「音频待录制（占位）」，2 秒后自动淡出；按钮本身正常显示「播放中…」再恢复「再听一次」，让学生知道这个交互是活的
3. 播放不限制次数，也不影响判分
4. 点选项：高亮选中，可以改选 → 已选择
5. 点提交：选项锁定，反馈区把题目数据里 `audioText` 的文字和拼音写出来
6. 点弹窗按钮：完成，调用 `finish()`

**技术上留个口子**：放一个 `<audio>` 元素、`src` 先空着。以后录音文件到位，把路径填进题目数据的 `audio` 字段，播放就是真的了——页面代码不用重写。

### 5.3 判定与反馈

- 判分是**真的**：以题目数据里的正确答案为准，选对才算对
- 全对：绿色「答对了！」＋「你听到的是 三 sān」＋ 一行解析
- 有错：红色「再想想」＋「正确答案：A 三 sān」＋ 同一行解析
- 答题过程中**不能显示任何答案文字**，选项本身除外
- `finish({ correct, seconds })`

### 5.4 模拟内容示例

- 音频（占位，不发声）：读出「三 sān」，`audioText: "三"`，`pinyin: "sān"`
- 题干：听一听，选出你听到的
- 选项：A 三 · B 四 · C 山 · D 伞
- 正确答案：A 三
- 解析：三 sān 是第一声，读得又平又高；四 sì 是第四声，往下掉。

### 5.5 为什么这题判分做真的

它的交互内核就是单选，早就有现成的；唯一的空缺只是音频文件。把判分做成真的，以后换录音就是纯粹的替换文件，一次返工都不用。

## 六、跟读模仿 · interaction-read-aloud.html

### 6.1 页面上有什么

- 题面：一行提示「听一遍，然后跟着读」
- 题型角标：跟读模仿
- 进度：第 1 / 1 题
- 作答区：
  - 今天要读的内容：词语或短句（大字）＋ 拼音
  - 「🔊 听范读」按钮（占位，不发声）
  - 「🎤 按住说话」大按钮
  - 占位结果卡（做完假流程后出现）
- 底部提示条：按住按钮读完再松开。 / Tahan tombol, baca, lalu lepaskan.
- 完成弹窗
- 右下角「🧩 占位演示」标签

### 6.2 操作逻辑与状态

1. 进入：待作答，「按住说话」可点
2. 点「听范读」：不发声，按钮下方出现「范读音频待录制（占位）」，2 秒后淡出
3. 按住「按住说话」：
   - 按下：按钮变成「正在录音…（占位）」，同时显示一个假的音量波形（CSS 动画，不接麦克风）
   - 松开：进入「识别中…（占位）」，转 1 秒
   - 结束：弹出占位结果卡
4. **也支持点一下开始、再点一下结束**（桌面演示时按住不方便，无障碍也需要）
5. 占位结果卡里给：
   - 顶部标记「占位演示 · 不是真实评分」
   - 一行「参考朗读：你好，nǐ hǎo」（这个是真的，给学生看正确读音）
   - 一组固定的示例评分（比如 发音 ★★★☆☆ / 流利度 ★★★★☆）
   - 一行小字「分数为占位示例，接入语音识别后替换」
6. 结果卡上放「完成」按钮 → 调用 `finish()`

### 6.3 判定与反馈

- **没有真判分**，占位结果卡每次显示同一组示例值
- `finish({ correct: true, seconds })` —— 如实写 `true`，因为占位版没有对错
- 弹窗文案要避免"你说得真好"这种基于真实评测的话，改成中性的「本题已完成」

### 6.4 模拟内容示例

- 要读的内容：你好（nǐ hǎo）
- 参考朗读：你好，nǐ hǎo——第一声 ＋ 第三声
- 占位评分：发音 ★★★☆☆ · 流利度 ★★★★☆ · 声调 ★★★☆☆

### 6.5 假流程的火候

整段假流程控制在 **2 秒以内**（录音态按多久学生自己定，识别态固定 1 秒）。不要为了像真的而转 5 秒圈，演示时拖时间。

## 七、看图说话 · interaction-picture-talk.html

### 7.1 页面上有什么

- 题面：一行提示「看这张图，用中文说一说法」
- 题型角标：看图说话
- 进度：第 1 / 1 题
- 作答区：
  - 一个正方形图槽（emoji 或真图，沿用二期的可替换槽位写法）
  - 提示词：「试试说：谁 ＋ 在做什么」
  - 「🎤 按住说话」大按钮
  - 占位结果卡
- 底部提示条：看图画，说一句完整的话。 / Lihat gambar, ucapkan satu kalimat lengkap.
- 完成弹窗
- 右下角「🧩 占位演示」标签

### 7.2 操作逻辑与状态

和跟读模仿完全一样（按住 → 假波形 → 识别中 1 秒 → 占位结果卡），区别只在内容：

- 没有「听范读」（看图说话本来就没有范读）
- 占位结果卡给的是**参考回答**，不是参考朗读，例如「参考答案：小朋友在跑步。」
- 示例评分维度换成：内容 ★★★☆☆ · 完整度 ★★★☆☆ · 发音 ★★★☆☆

### 7.3 判定与反馈

- 没有真判分，占位结果卡固定
- `finish({ correct: true, seconds })`
- 弹窗文案同样保持中性

### 7.4 模拟内容示例

- 图槽：🏃（以后换 `picture-talk-running.png`）
- 提示词：谁 ＋ 在做什么
- 参考答案：小朋友在跑步。 / Anak itu sedang berlari.
- 占位评分：内容 ★★★☆☆ · 完整度 ★★★☆☆ · 发音 ★★★☆☆

## 八、开放问答 · interaction-open-qa.html

### 8.1 页面上有什么

- 题面：一个问题（大字）＋ 印尼语对照
- 题型角标：开放问答
- 进度：第 1 / 1 题
- 作答区：
  - 问题下面给 2–3 个提示词（帮学生组织语言，不是选项）
  - 「🎤 按住说话」大按钮
  - 占位结果卡
- 底部提示条：说一两句就行，不用长。 / Cukup satu atau dua kalimat.
- 完成弹窗
- 右下角「🧩 占位演示」标签

### 8.2 操作逻辑与状态

和跟读模仿一样（按住 → 假波形 → 识别中 1 秒 → 占位结果卡）。

**不做打字版**：一期填空已经因为印尼学生打不出中文、从"手打"改成了"点词库"，所以开放问答打字这条路走不通，占位版也直接用语音形态。

### 8.3 判定与反馈

- 没有真判分，占位结果卡固定
- 占位结果卡给**参考答案**＋「你可以这样说」的句式提示
- `finish({ correct: true, seconds })`
- 弹窗文案中性

### 8.4 模拟内容示例

- 问题：你周末喜欢做什么？（Akhir pekan kamu suka melakukan apa?）
- 提示词：听音乐 · 打篮球 · 和朋友玩
- 参考答案：我周末喜欢听音乐。
- 占位评分：内容 ★★★☆☆ · 完整度 ★★★☆☆ · 发音 ★★★☆☆

## 九、验收项（占位版标准）

一期任务书第六节的通用验收清单适用，另外加上这几条：

- [ ] 页面角落固定显示「🧩 占位演示」标签，不随滚动跑，也没挡住右下角悬浮按钮
- [ ] 所有占位提示都写清了"占位""待录制""不是真实评分"这类字样
- [ ] 假流程**全程不弹麦克风授权框**（因为没调麦克风）
- [ ] 假识别过程不超过 1 秒，整段假流程不超过 2 秒
- [ ] 听音选图/选词的判分确实是真的，能答对也能答错
- [ ] 题型体验清单里这 4 行显示「可体验 · 占位」，和正式的区分开
- [ ] 课堂随机抽题不会抽到这 4 个（手动进入体验不受影响）
- [ ] 完整流程能跑通：进入 → 作答 → 提交 → 结果 → 完成弹窗 →「换一个题型」
- [ ] 课堂模式下能记进度、能解锁下一题
- [ ] `shared/activity-types.js` 里自己那条的 `ready` 和 `placeholder` 都设好了

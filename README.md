# AI Chinese Cloud 四角色课堂管理与学习原型

> 当前版本 **v2.2.0**：在 v2.1.0 三角色后台的基础上新增「学校教务端」与「成绩中心」，并补齐课堂设计页、互动设计库与学校管理。

同一个工程内包含两套可联动的原型：

- `/`：面向学生的移动学习端，保留原有的课堂互动、预习与完成流程。
- `/admin/`：学生、教师、教学管理、学校教务四角色共用的课堂管理后台，入口页按角色进入对应工作台。

## 运行

```bash
npm install
npm run dev
```

打开：

- 学习端：`http://127.0.0.1:5173/`
- 管理后台：`http://127.0.0.1:5173/admin/`

生产构建与测试：

```bash
npm test
npm run build
npm run preview
```

## 后台能力

### 学生端

- 按单次班（单个课次）或系列班（同一主题下多个课节组成的整套课程）预约课程，查看余位、候补和自动转正结果。
- 按用户时区查看课程时间，取消预约或退出候补。
- 查看并下载课前、课中、课后材料。
- 完成十八类互动：连线、翻牌、选择、排序、填空、投票、看图单选、图片—词语连线、情景选择、对话补全，以及拼音匹配、分类归组、拼字组词、找错误、听音选词、跟读模仿、看图说话、开放问答。
- 查看得分、用时、尝试次数和错题复习建议。
- 在「成绩统计」中按 7 天、30 天、90 天或自定义时间范围查看综合成绩、互动 / 作业 / 考试分项趋势和成绩明细；学生只看到自己的数据。

### 教师端

- 查看本人课表、预约名单和班级互动结果。
- 使用十八类模板设计互动（含图槽、拼音、语音占位评分等字段），支持预览、发布、版本历史和回滚。
- 管理课程材料、模拟上传新版本并关联到具体课节阶段。
- 在课堂设计页按课次配置互动：新建 / 编辑 / 预览整套互动，或把设计的作用范围调整为单次课次或该课节全部课次。
- 教师端名单只读，不展示学生联系方式。
- 在「学生成绩」中按时间与班级查看本人所教学生的综合成绩和成绩构成，管理正式作业 / 考试并批量录分；重复互动按区间内最好成绩计算。

### 教学管理端

- 管理不限层级的自由课程目录、课节、单次班次与系列班；系列班由同一主题目录下的多个课节组成，AI 先按首节课时间与课节间隔预排每节课的日期时间，人可以逐节调整后再创建课次。
- 同一个课节可以排给不同班级，每次上课都会形成独立课次，名单、作答和成绩互不影响。
- 配置教师、容量、预约截止和取消截止时间，自动检测教师冲突。
- 管理学生档案、学习偏好和进度。
- 代学生预约、候补、改约和取消；强制操作需要填写原因并写入审计日志。
- 查看和回滚教师发布的互动，下架或恢复课程材料。
- 维护学校主数据、学校成员关系，以及平台默认与各校成绩规则。
- 维护稳定班级与成员、设置分版本的成绩权重，并可代学生在正式考核中补录、缺考或免考标记。

### 学校教务端

- 以本校为范围查看教学运行态势：已发布课次、报名容量与待处理报名、待处理改约申请。
- 为本校课次排课、安排教师，审核报名与改约，并管理本校学生档案。
- 按时间区间与班级查看教师教学表现排名，可搜索教师、导出 CSV，并进入单个教师的明细页。
- 课程内容仍由平台教学管理统一维护，学校教务只处理本校范围内的排课、学生与考务。

## 学生端题型扩展

学生端 18 种题型全部接入后台互动设计：教师可在编辑器里新建、配置、从模板库引用，并在预览里按真实答题流程检查。前 10 类为 choice / order / fill / poll / match / memory / picture / picture-match / situation / dialogue，第三批新增 8 类：pinyin-match（拼音—汉字—含义匹配）、category（分类归组）、word-build（拼字 / 组词）、correction（找错误 / 改错）、listening（听音选图 / 选词）、read-aloud（跟读模仿）、picture-talk（看图说话）、open-qa（开放问答）。

### 预制互动模板库

- 模板库按 **18 种题型 × 14 个主题 × 3 个难度** 生成，共 756 套，题型、主题、难度三个维度都能筛（题型筛选条上带数量角标）。
- 14 个主题：问候与寒暄、自我介绍、数字与年龄、食物与口味、餐厅点餐、时间与日期、天气与季节、购物与价格、方位与问路、家庭与朋友、爱好与运动、交通与出行、学校与学习用品、动作与日常。
- 同一个主题的 18 种题型共用一套素材（词表、排序句、填空句、情景、对话、错句、归类、看图说话、开放问答），老师换题型不用重写内容。
- 浏览顺序按题型轮转，第一屏就能看到多种题型；筛了某个题型则按难度 + 主题排。
- 模板库以种子为准：内置模板随版本刷新，老师自己保存的模板保留；学生端与后台的题型 key 始终是同一套 18 个。

### 后台与学习端的数据约定

- 题型统一使用 `InteractionType`：`picture`（看图单选）、`picture-match`（图片—词语连线）、`situation`（情景选择）、`dialogue`（对话补全）。
- 图槽统一为 `{ icon, image, alt }`：`image` 为空时显示 emoji，填了图片地址就显示真图；`alt` 同时作为无障碍文案。
- 拼音、点评等辅助文字放在选项的 `hint` 字段；图片—词语连线的右列拼音放在配对的 `rightPinyin`。
- 第三批题型的字段与同名学生端页面一一对应：`groups` + `words`（分类归组，词语的 `group` 指向类别 id）、`answer` / `tileBank`（拼字组词）、`badWords` / `fixedSentence`（找错误）、`pinyinGroups`（拼音匹配）、`audioSrc` / `audioText`（听力）、`scores` / `sampleAnswer`（三类语音题型的占位评分）。
- 跟读、看图说话、开放问答沿用学生端的占位版流程：不调用麦克风、不弹授权，录音与评分都是演示值；`audioSrc` 或图片填上真实地址后自动改为真播放 / 真图片。
- 新题型和老题型可以混排在同一个互动集中；后台播放器会按题型渲染对应交互。
- 模板库为这 8 类新题型各准备了初级、中级两套示例模板（共 16 套），并有「互动体验 · 八大新题型」示例互动集可一键预览。
- 老版本本地数据在打开后台时会按模板 id 自动补齐新题型模板与示例互动，不需要重置演示数据。

## 原学生端原型说明（第一批）

学生端手机原型里已经跑通 2 种题型：连线配对（match.html）、翻牌记忆（memory.html）。其余 4 种按下面的约定认领实现，一人一个页面：单选/多选、排序、填空、投票。

### 课堂上呈现什么由老师端决定

课堂页（classroom.html）展示的三关是“本课已布置的互动”，学生端不做随机抽题；老师端发布后，学生端收到的就是老师布置的内容。

### 题型体验按钮

学生端每个页面右下角有一个悬浮按钮「题型体验」（在原有“演示”按钮上方）。点开是一张题型清单，列出全部题型，点任意一行直接进入该题型单题体验。体验不计分，也不影响课堂页那三关的进度；做完可以再点按钮换别的题型。清单里灰底、标着“待认领”的题型表示页面还没做完。

也可以直接用网址展开清单：在任意页面地址后面加 `?activities=1`（例如 `classroom.html?activities=1`），打开页面就会自动弹出题型清单。题型页面完成弹窗里的「换一个题型」指向这里。

### 每个页面的硬约定

1. 文件名不要改，入口固定是 interaction-xxx.html。
2. 外壳复用现有样式类：app-shell、status-bar、page-header、game-intro、progress-pill、helper-note、modal-overlay、completion-modal、primary-button。
3. 只新增自己的样式文件 interaction-xxx.css，不要修改 styles.css，多人并行会冲突。
4. 完成时调用公共脚本：

       AICloudActivity.finish({ correct: true, seconds: 12 });

   体验模式（网址里只有 type 参数）：不记账，页面自己弹完成弹窗。
   课堂模式（网址带 mode=class 和 slot）：写入进度；做完同样弹完成弹窗（与体验模式同一套），点【返回课堂】回课堂页；三关都完成后回到课堂页弹一次大恭喜。
   体验模式弹窗正在分批换成公共模具：换好的页面按钮是【返回课堂】（指向 `classroom.html`）＋【再练一次】（就地重开）；还没换的页面维持旧样。新接线一律按 `docs/视觉打磨规范-v0.3.md` 来（第五节 = 弹窗规格，第九节 = 接线进度；传 tier、不自己画弹窗；第十三节 = 双语按钮）。
5. 页面里可以随时用 AICloudActivity.context() 拿到当前是第几题、哪种题型。
6. 做完之后，把 shared/activity-types.js 里自己那条的 ready 改成 true，题型清单里就会变成“可体验”。

逐题型的详细任务书见 docs/ 目录。
